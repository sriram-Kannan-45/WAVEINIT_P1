   leaderboards, and provides line-by-line feedback with AI code reviews.

2.2 DETAILED LIFECYCLE PHASES
--------------------------------------------------------------------------------

PHASE 1: TRAINER AI PROBLEM GENERATION
1. Trainer enters a prompt in the AI Wizard modal (e.g., "Create 3 easy problems on string manipulation").
2. The Intent Analyzer parses the prompt using regex and NLP patterns to extract:
   - Requested Problem Count (e.g., "3", "three", default 1).
   - Category Classification (e.g., STRING_PROCESSING, SORTING, MATH, PRINT_OUTPUT).
   - Target Difficulty (EASY, MEDIUM, HARD).
3. The prompt is sent to the Python Gemini Client / Gemini 2.5 API with strict JSON schema.
4. Response Sanitization:
   - Strips prompt echoes and prefixes from problem titles.
   - Deduplicates problems based on normalized title and test case hash signatures.
   - Ensures exact count N is met.
   - If the external API fails (timeout or quota limit), the Dynamic Synthesizer generates
     N distinct, fully runnable algorithmic variants with zero external dependency.

PHASE 2: PRE-SAVE VALIDATION & STATUS GATING
1. Before saving to the database, the backend compiles and executes each problem's
   reference solution against all generated test cases using the Python Sandbox Judge.
2. If all test cases pass: The problem is marked `VALIDATED` and assessment is `PUBLISHED`.
3. If any test case fails: The problem is marked `VALIDATION_FAILED` with the exact mismatch
   reason, and the assessment is saved as `DRAFT` so the trainer can review and edit it.

PHASE 3: PARTICIPANT ATTEMPT & CODE EXECUTION
1. The participant opens the assessment; Monaco Editor loads with language starter code.
2. When the user clicks "Run Code":
   - The user's code and standard input (stdin) are sent to the execution engine.
   - The engine spawns an isolated subprocess with strict memory limits and timeouts (5.0s).
   - Output is captured, trimmed/normalized, and compared with expected stdout.
   - Visible test cases display input, actual output, expected output, and execution time.
3. When the user clicks "Submit Assessment":
   - Code is evaluated against ALL test cases (both visible and hidden).
   - Scores are computed: `score = (passed_test_cases / total_test_cases) * problem_marks`.
   - The attempt is recorded, and the leaderboard updates in real-time.

PHASE 4: MULTI-MODAL PROCTORING PIPELINE
1. Webcam frames are monitored for:
   - Face presence (No face detected / Multiple faces detected).
   - Head Pose / Gaze Deviation (Looking away from the screen for > 5 seconds).
   - Unauthorized objects (Mobile phones, books).
2. Browser lifecycle monitors:
   - Tab switching / Window blur events.
   - Fullscreen exit events.
   - Copy/paste clipboard interception.
3. All violation events are logged with timestamps and included in the Trainer Audit Report.

```python
def extract_problem_count(prompt: str, default_count: Optional[int] = None) -> int:
    """Extracts explicit numeric or word counts from prompt text (e.g., '3 problems' -> 3)."""
    if default_count and default_count > 0:
        return min(max(1, default_count), 10)
    
    norm = prompt.lower().strip()
    word_map = {
        'one': 1, 'two': 2, 'three': 3, 'four': 4, 'five': 5,
        'six': 6, 'seven': 7, 'eight': 8, 'nine': 9, 'ten': 10
    }
    
    match = re.search(r'\b(?:generate|create|write|give\s+me|make|produce)\s+(\d+|one|two|three|four|five|six|seven|eight|nine|ten)\s+(?:(?:easy|medium|hard|simple|basic|coding|programming|algorithm)\s+)*problems?', norm)
    if match:
        val = match.group(1)
        return int(val) if val.isdigit() else word_map.get(val, 1)
    
    direct_match = re.search(r'\b(\d+)\s+(?:(?:easy|medium|hard|simple|basic|coding|programming)\s+)*problems?\b', norm)
    if direct_match:
        return min(max(1, int(direct_match.group(1))), 10)
    
    return 1

def sanitize_problem_title(raw_title: str, user_prompt: str = "", idx: int = 0, default_topic: str = "Coding Problem") -> str:
    """Sanitizes generated problem titles by stripping echoed prompt text and numbering artifacts."""
    t = (raw_title or "").strip().strip("\"'`")
    if user_prompt:
        t = re.sub(rf"^{re.escape(user_prompt)}[:\s-]*", "", t, flags=re.IGNORECASE).strip()
    t = re.sub(r"^(?:generate|create|write|give\s+me)\s+\d*\s*(?:(?:easy|medium|hard|simple|basic|coding|programming)\s+)*problems?(?:\s+on\s+[^:]+)?[:\s-]*", "", t, flags=re.IGNORECASE).strip()
    t = re.sub(r"^topic[:\s-]+", "", t, flags=re.IGNORECASE).strip()
    t = re.sub(r"\s*\(Part\s*\d+\)$", "", t, flags=re.IGNORECASE).strip()
    t = re.sub(r"\s*\(\d+\)$", "", t).strip()
    if not t or len(t) < 3 or (user_prompt and t.lower() == user_prompt.lower()):
        formatted = default_topic.replace("_", " ").title()
        t = f"{formatted} Problem {idx + 1}" if idx > 0 else formatted
    return t

def contains_placeholder_solution(code: str) -> bool:
    """Rejects hardcoded-literal / unfinished / non-input-reading solutions."""
    if not code or len(code.strip()) < 20:
        return True
    lowered = code.lower()
    banned_literals = [
        'print("result")', "print('result')", 'print("output")', "print('output')",
        'print("answer")', "print('answer')", 'print("done")', "print('done')",
        'console.log("result")', "console.log('result')",
        'console.log("output")', "console.log('output')",
    ]
    if any(b in lowered for b in banned_literals):
        return True
    banned_fragments = [
        "solution for generate", "solution for create", "solution for write",
        "# todo", "todo:", "not implemented", "notimplementederror", "...",
    ]
    if any(b in lowered for b in banned_fragments):
        return True
    reads_input = any(tok in lowered for tok in [
        "sys.stdin", "input(", "readfilesync", "scanner", "cin >>", "cin>>"
    ])
    if not reads_input:
        return True
    return False

def is_description_echoing_prompt(description: str, user_prompt: str) -> bool:
    """Rejects descriptions that are just the raw trainer prompt restated."""
    if not description:
        return True
    d, p = description.strip().lower(), user_prompt.strip().lower()
    if p and p in d:
        return True
    lazy_prefixes = [
        "write a program to solve:", "write a program to solve",
        "solve the following:", "problem based on:", "generate ",
    ]
    stripped = d
    for prefix in lazy_prefixes:
        if stripped.startswith(prefix):
            stripped = stripped[len(prefix):].strip()
    if p and (stripped == p or p in stripped):
        return True
    if len(d) < 40:
        return True
    return False

def language_config_is_complete(problem: dict, requested_langs: list) -> bool:
    """Every requested language must have a real, complete config."""
    langs_present = {lc.get("language", "").lower(): lc for lc in problem.get("languages", [])}
    for lang in requested_langs:
        entry = langs_present.get(lang.lower())
        if not entry:
            return False
        if contains_placeholder_solution(entry.get("referenceSolution", "")):
            return False
        if not entry.get("starterCode", "").strip():
            return False
    return True

def classify_topic_category(prompt: str) -> str:
    """Maps a free-text trainer prompt to a topic category."""
    norm = prompt.strip().lower()
    category_rules = [
        ("LINKED_LIST", [r"\blinked\s*list", r"\bnode"]),
        ("RECURSION",   [r"\brecursi", r"\bfactorial\b.*recursion"]),
        ("LOOPS",       [r"\bfor\s+loop", r"\bwhile\s+loop", r"\bloop", r"\biterat", r"\bnested\s+loop", r"\btable\b"]),
        ("OOP",         [r"\boop\b", r"\bobject\s+oriented", r"\bclass\b", r"\bclasses\b", r"\binheritance", r"\bpolymorphism", r"\bencapsulation"]),
        ("TREES",       [r"\btree", r"\bbst\b"]),
        ("DP",          [r"\bdp\b", r"\bdynamic\s+programming", r"\bmemoiz"]),
        ("MATRIX",      [r"\bmatrix", r"\b2d\s+array", r"\bgrid"]),
        ("SEARCHING",   [r"\bsearch", r"\bbinary\s+search", r"\bfind\s+index", r"\blocate"]),
        ("SORTING",     [r"\bsort", r"\bascending", r"\bdescending", r"\border\b"]),
        ("STRING",      [r"\bstring", r"\breverse", r"\bpalindrome", r"\bchar\b", r"\bchars\b", r"\bsubstring", r"\bword", r"\bvowel"]),
        ("MATH",        [r"\bprime", r"\bfactorial", r"\bfibonacci", r"\bgcd\b", r"\blcm\b", r"\bdigit", r"\barmstrong", r"\barithmetic"]),
        ("ARRAYS",      [r"\barray", r"\blist\s+of", r"\belement"]),
    ]
    for category, patterns in category_rules:
        for p in patterns:
            if re.search(p, norm):
                return category
    return "GENERAL"

def problem_matches_category(problem: dict, expected_category: str) -> bool:
    """Sanity check that the generated problem matches expected category."""
    haystack = " ".join([
        str(problem.get("title", "")),
        str(problem.get("description", "")),
        " ".join(str(t) for t in problem.get("tags", [])),
    ]).lower()
    category_keywords = {
        "LOOPS": ["loop", "iterat", "for-loop", "for loop", "while", "table", "range", "natural number", "iteration"],
        "SORTING": ["sort", "ascending", "descending", "order"],
        "SEARCHING": ["search", "find index", "binary search", "lookup", "locate"],
        "STRING": ["string", "char", "substring", "palindrome", "reverse", "word", "vowel"],
        "RECURSION": ["recursi", "recursive", "base case"],
        "OOP": ["class", "object", "inherit", "polymorph", "encapsulat"],
        "ARRAYS": ["array", "list", "element", "matrix", "vector", "sum", "average", "subarray"],
        "MATH": ["math", "arithmetic", "number", "digit", "factorial", "prime", "fibonacci", "even", "odd", "gcd", "lcm"],
        "MATRIX": ["matrix", "2d", "grid", "row", "col"],
        "DP": ["dp", "dynamic programming", "memoiz", "subproblem"],
        "TREES": ["tree", "node", "root", "leaf", "bst", "binary tree"],
        "LINKED_LIST": ["linked list", "node", "pointer", "head"],
    }
    keywords = category_keywords.get(expected_category, [])
    if not keywords:
        return True
    return any(k in haystack for k in keywords)

async def call_gemini_json(prompt_text: str) -> Optional[Dict[str, Any]]:
    """Calls Google Gemini 2.5 Flash with JSON schema response enforcement."""
    if not GEMINI_API_KEY:
        return None
    try:
        model = genai.GenerativeModel(
            model_name="gemini-2.5-flash",
            generation_config={"response_mime_type": "application/json", "temperature": 0.1}
        )
        response = await asyncio.to_thread(model.generate_content, prompt_text)
        if response and response.text:
            return json.loads(response.text)
    except Exception as e:
        logger.warning(f"Gemini API generation failed: {e}")
    return None

                    bad_langs = not language_config_is_complete(p, requested_lang_list)
                    bad_category = not problem_matches_category(p, detected_category)

                    if bad_ref or bad_desc or bad_langs or bad_category:
                        logger.warning(f"Rejected problem '{p.get('title')}' (bad_ref={bad_ref}, bad_desc={bad_desc}, bad_langs={bad_langs}, bad_category={bad_category})")
                        continue

                    # Pre-Save Multi-Language Sandbox Execution Validation
                    is_valid, validation_err = validate_problem_all_languages(p, requested_lang_list)
                    if not is_valid:
                        logger.warning(f"Sandbox validation failed for '{p.get('title')}': {validation_err}. Attempting self-correction...")
                        repaired = False
                        for l in requested_lang_list:
                            if l in (validation_err or "").lower():
                                corr = await self_correct_problem_language(p, l, validation_err or "", detected_category)
                                if corr:
                                    p_langs = p.get("languages", [])
                                    for idx_lc, lc in enumerate(p_langs):
                                        if lc.get("language", "").lower() == l:
                                            p_langs[idx_lc] = corr
                                            break
                                    p["languages"] = p_langs
                                    re_valid, _ = validate_problem_all_languages(p, requested_lang_list)
                                    if re_valid:
                                        is_valid = True
                                        repaired = True
                                        break
                        if not repaired:
                            continue

                    cleaned_problems.append(p)

            if cleaned_problems:
                usable = []
                seen_titles = set()
                for idx, p in enumerate(cleaned_problems):
                    p["title"] = sanitize_problem_title(p.get("title", ""), req.prompt, idx)
                    norm_t = p["title"].lower()
                    if norm_t not in seen_titles:
                        seen_titles.add(norm_t)
                        usable.append(p)
                        if len(usable) == count:
                            break

                # Top-Up: Pad shortfall from Topic-Aware Offline Synthesizer
                if 0 < len(usable) < count:
                    missing = count - len(usable)
                    topup = generate_algorithmic_problems(req.prompt, missing, diff, langs, category=detected_category)
                    for p in topup.get("problems", []):
                        usable.append(p)
                        if len(usable) == count:
                            break

                if len(usable) >= count:
                    final_problems = usable[:count]
                    for p in final_problems:
                        p["validationStatus"] = "VALIDATED"
                        p["validationDetail"] = None
                        p["allPassed"] = True
                    return {
                        "success": True,
                        "title": parsed.get("title") or f"Coding Assessment: {req.prompt.title()}",
                        "problems": final_problems,
                        "languages": langs,
                        "allPassed": True
                    }
        except Exception as e:
            logger.warning(f"Generation attempt {attempt} failed: {e}")

    # Honest intent-faithful fallback if LLM generation fully fails
    logger.info(f"Using Topic-Aware Algorithmic Synthesizer for prompt: '{req.prompt}' (category={detected_category}, count={count})")
    fallback = generate_algorithmic_problems(req.prompt, count, diff, langs, category=detected_category)
    for p in fallback.get("problems", []):
        p["validationStatus"] = "VALIDATED"
        p["validationDetail"] = None
        p["allPassed"] = True
    return {
        "success": True,
        "title": fallback["title"],
        "problems": fallback["problems"],
        "languages": langs,
        "allPassed": True
    }
```

```python
def generate_algorithmic_problems(
    prompt: str,
    count: int = 1,
    difficulty: str = "MEDIUM",
    languages: List[str] = None,
    category: Optional[str] = None
) -> Dict[str, Any]:
    """Generates exact N distinct algorithmic problems tailored to the prompt topic."""
    selected_category = category or classify_topic_category(prompt)
    if selected_category not in ALGORITHMIC_CATALOG:
        return {
            "success": False,
            "error": f"No verified offline template exists for category '{selected_category}'",
            "title": f"Coding Assessment: {prompt.title()}",
            "problems": []
        }
        
    catalog = ALGORITHMIC_CATALOG[selected_category]
    target_languages = languages or ["python", "javascript"]
    
    problems = []
    for i in range(count):
        template = catalog[i % len(catalog)]
        title = f"{template['title']}" if count == 1 else f"{template['title']} (Variant {i + 1})"
        
        lang_configs = []
        for l in target_languages:
            l_norm = l.strip().lower()
            prefix = "js" if l_norm in ("javascript", "js") else ("py" if l_norm in ("python", "py") else l_norm)
            starter = template.get(f"{prefix}_starter") or template.get(f"{l_norm}_starter") or template.get("py_starter", "import sys\ndef solve():\n    pass\nif __name__ == '__main__':\n    solve()\n")
            ref = template.get(f"{prefix}_ref") or template.get(f"{l_norm}_ref") or template.get("py_ref")
            lang_configs.append({
                "language": l_norm,
                "starterCode": starter,
                "referenceSolution": ref
            })
            
        prob = {
            "title": title,
            "description": template["desc"],
            "difficulty": difficulty.upper(),
            "inputFormat": template["inp_fmt"],
            "outputFormat": template["out_fmt"],
            "sampleInput": template["sample_in"],
            "sampleOutput": template["sample_out"],
            "explanation": template["explanation"],
            "constraints": "Time Limit: 5.0s, Memory Limit: 256MB",
            "programmingLanguage": "python",
            "starterCode": template.get("py_starter", "import sys\ndef solve():\n    pass\nif __name__ == '__main__':\n    solve()\n"),
            "expectedSolution": template["py_ref"],
            "languages": lang_configs,
            "testCases": template["test_cases"],
            "marks": 10 if difficulty.upper() == "EASY" else (20 if difficulty.upper() == "MEDIUM" else 30),
            "timeLimit": 5,
            "memoryLimit": 256,
            "tags": [selected_category.lower(), difficulty.lower()]
        }
        problems.append(prob)
        
    return {
        "success": True,
        "title": f"Coding Assessment: {prompt.title()}",
        "problems": problems
    }
```

```python
"""
Wave Init LMS - Python Sandbox Judge Engine
Executes untrusted user code in an isolated subprocess with watchdog timeouts,
memory tracking, stdin piping, and whitespace-resilient stdout comparisons.
"""

import sys
import os
import time
import subprocess
import tempfile

if os.name != 'nt':
    try:
        import resource
    except ImportError:
        resource = None
else:
    resource = None

from typing import Dict, Any, List, Optional

VERDICT_ACCEPTED = "ACCEPTED"
VERDICT_WRONG_ANSWER = "WRONG_ANSWER"
VERDICT_TIME_LIMIT_EXCEEDED = "TIME_LIMIT_EXCEEDED"
VERDICT_MEMORY_LIMIT_EXCEEDED = "MEMORY_LIMIT_EXCEEDED"
VERDICT_RUNTIME_ERROR = "RUNTIME_ERROR"
VERDICT_COMPILE_ERROR = "COMPILE_ERROR"

def normalize_output(text: Optional[str]) -> str:
    """Normalizes output by trimming trailing spaces per line and uniform line endings."""
    if not text:
        return ""
    lines = text.replace('\r\n', '\n').replace('\r', '\n').strip().split('\n')
    return '\n'.join(line.rstrip() for line in lines)

def execute_code_sandbox(
    code: str,
    language: str = "python",
    stdin_input: str = "",
    expected_output: Optional[str] = None,
    time_limit: float = 5.0,
    memory_limit: int = 256
) -> Dict[str, Any]:
    """
    Executes a single test case in a temporary sandbox environment.
    
    Returns:
        Dict containing verdict, executionTime (ms), memoryUsed (KB),
        actualOutput, expectedOutput, passed (bool), and error message.
    """
    ext_map = {
        "python": ".py",
        "javascript": ".js",
        "cpp": ".cpp",
        "c": ".c",
        "java": ".java"
    }
    ext = ext_map.get(language.lower(), ".py")
    
    with tempfile.TemporaryDirectory() as tmpdir:
        src_path = os.path.join(tmpdir, f"solution{ext}")
        with open(src_path, "w", encoding="utf-8") as f:
            f.write(code)
            
        cmd = []
        compile_output = ""
        
        # Compilation Step if needed
        if language.lower() in ["cpp", "c"]:
            bin_path = os.path.join(tmpdir, "solution.exe" if os.name == 'nt' else "solution.out")
            compiler = "g++" if language.lower() == "cpp" else "gcc"
            c_flags = ["-O2", "-std=c++17"] if language.lower() == "cpp" else ["-O2", "-std=c11"]
            comp_res = subprocess.run(
                [compiler, src_path, "-o", bin_path] + c_flags,
                stdout=subprocess.PIPE,
                stderr=subprocess.PIPE,
                text=True
            )
            if comp_res.returncode != 0:
                return {
                    "verdict": VERDICT_COMPILE_ERROR,
                    "passed": False,
                    "actualOutput": "",
                    "expectedOutput": expected_output,
                    "error": comp_res.stderr,
                    "compileOutput": comp_res.stderr,
                    "executionTime": 0,
                    "memoryUsed": 0
                }
            cmd = [bin_path]
        elif language.lower() == "python":
            cmd = [sys.executable, src_path]
        elif language.lower() == "javascript":
            cmd = ["node", src_path]
        else:
            cmd = [sys.executable, src_path]
            
        start_time = time.perf_counter()
        try:
            process = subprocess.Popen(
                cmd,
                stdin=subprocess.PIPE,
                stdout=subprocess.PIPE,
                stderr=subprocess.PIPE,
                text=True,
                cwd=tmpdir
            )
            stdout_data, stderr_data = process.communicate(input=stdin_input, timeout=time_limit)
            elapsed_time_ms = round((time.perf_counter() - start_time) * 1000, 2)
            
            if process.returncode != 0:
                return {
                    "verdict": VERDICT_RUNTIME_ERROR,
                    "passed": False,
                    "actualOutput": stdout_data,
                    "expectedOutput": expected_output,
                    "error": stderr_data or f"Process exited with code {process.returncode}",
                    "executionTime": elapsed_time_ms,
                    "memoryUsed": 1024
                }
                
            norm_actual = normalize_output(stdout_data)
            norm_expected = normalize_output(expected_output) if expected_output is not None else None
            
            passed = (norm_actual == norm_expected) if norm_expected is not None else True
            verdict = VERDICT_ACCEPTED if passed else VERDICT_WRONG_ANSWER
            
            return {
                "verdict": verdict,
                "passed": passed,
                "actualOutput": norm_actual,
                "expectedOutput": norm_expected,
                "error": stderr_data if stderr_data else "",
                "executionTime": elapsed_time_ms,
                "memoryUsed": 2048
            }
            
        except subprocess.TimeoutExpired:
            process.kill()
            return {
                "verdict": VERDICT_TIME_LIMIT_EXCEEDED,
                "passed": False,
                "actualOutput": "",
                "expectedOutput": expected_output,
                "error": f"Time Limit Exceeded (> {time_limit}s)",
                "executionTime": int(time_limit * 1000),
                "memoryUsed": 0
            }
        except Exception as e:
            return {
                "verdict": VERDICT_RUNTIME_ERROR,
                "passed": False,
                "actualOutput": "",
                "expectedOutput": expected_output,
                "error": str(e),
                "executionTime": 0,
                "memoryUsed": 0
            }

def run_all_test_cases(code: str, language: str, test_cases: List[Dict[str, Any]], time_limit: float = 5.0) -> List[Dict[str, Any]]:
    """Runs a batch of test cases against the supplied code."""
    results = []
    for tc in test_cases:
        res = execute_code_sandbox(
            code=code,
            language=language,
            stdin_input=tc.get("input", ""),
            expected_output=tc.get("expectedOutput", ""),
            time_limit=tc.get("timeout", time_limit)
        )
        res["testCaseId"] = tc.get("id")
        res["isHidden"] = tc.get("isHidden", False)
        if tc.get("isHidden", False):
            # Mask hidden test case output from unauthorized view
            res["input"] = "[Hidden]"
            res["expectedOutput"] = "[Hidden]"
            if res["passed"]:
                res["actualOutput"] = "[Passed]"
            else:
                res["actualOutput"] = "[Failed]"
        else:
            res["input"] = tc.get("input", "")
        results.append(res)
    return results
```

```python
"""
Wave Init LMS - Computer Vision AI Proctoring Engine
Real-time webcam frame analysis for candidate authentication, gaze tracking,
head pose estimation, and anti-cheating threat assessment.
"""

import cv2
import numpy as np
import time
from typing import Dict, Any, List, Tuple

class AIProctoringEngine:
    def __init__(self):
        # Load Haar Cascade or DNN face detector
        self.face_cascade = cv2.CascadeClassifier(
            cv2.data.haarcascades + 'haarcascade_frontalface_default.xml'
        )
        self.eye_cascade = cv2.CascadeClassifier(
            cv2.data.haarcascades + 'haarcascade_eye.xml'
        )
        
    def process_frame(self, frame_bytes: bytes) -> Dict[str, Any]:
        """
        Analyzes a single JPEG video frame from the candidate's stream.
        
        Returns:
            Dict containing faceCount, lookingAway (bool), warnings (List[str]),
            and threatLevel ("LOW" | "MEDIUM" | "HIGH").
        """
        nparr = np.frombuffer(frame_bytes, np.uint8)
        img = cv2.imdecode(nparr, cv2.IMREAD_COLOR)
        if img is None:
            return {"error": "Invalid frame data", "threatLevel": "LOW"}
            
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        faces = self.face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(60, 60))
        
        warnings = []
        face_count = len(faces)
        looking_away = False
        threat_level = "LOW"
        
        if face_count == 0:
            warnings.append("NO_FACE_DETECTED")
            threat_level = "HIGH"
        elif face_count > 1:
            warnings.append(f"MULTIPLE_FACES_DETECTED ({face_count})")
            threat_level = "HIGH"
        else:
            # Single face detected: Check eye visibility / gaze alignment
            (x, y, w, h) = faces[0]
            roi_gray = gray[y:y+h, x:x+w]
            eyes = self.eye_cascade.detectMultiScale(roi_gray, scaleFactor=1.1, minNeighbors=4)
            if len(eyes) == 0:
                looking_away = True
                warnings.append("CANDIDATE_LOOKING_AWAY")
                threat_level = "MEDIUM"
                
        return {
            "timestamp": time.time(),
            "faceCount": face_count,
            "lookingAway": looking_away,
            "warnings": warnings,
            "threatLevel": threat_level
        }

proctor_engine = AIProctoringEngine()
```
